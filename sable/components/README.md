# sable/components

`Sable.Components`: the BB10-style control library, a QML module beside
`Marathon.Silica`. Planned: Page, TitleBar, ActionBar (signature action, at most
three actions, overflow), ActionMenu, ContextHighlight, TabbedPane,
NavigationPane (Back, swipe back, peek), ListView with focus and letter
shortcuts, Toast, SegmentedControl. Theme tokens go in `sable-theme.json`, read
by QML and Rust alike.
